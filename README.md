# 花花守护队

给 5 岁小朋友玩的花园守护小游戏（原创角色和画面）：调皮的果冻想偷野餐桌上的小蛋糕，种下会吹泡泡的花朵把它们哄睡，果冻会睡在泡泡里飘走。

- 玩法：点星星收集 → 点上面的花朵卡片 → 再点草地种下。全程只需要点，不用拖。
- 5 种花朋友：星星花（送星星）、泡泡花（吹泡泡）、胖胖菇（挡住果冻）、雪花铃（让果冻变慢）、蒲公英（一口气把一整行果冻吹回去）。
- 8 关，难度很慢地增加；蛋糕全被拿走才算输，可以马上再来。
- 横屏玩最好；竖着拿手机时画面会自动转成横的，把手机横过来就行（不用解锁屏幕旋转）。
- 中文语音提示，音效和音乐都是程序生成的，没有任何外部资源，国内可以直接打开。
- 用 iPhone/iPad 的 Safari 打开后，点"分享 → 添加到主屏幕"，就像一个 App；打开过一次以后没网也能玩。
- 记得关掉手机静音键，第一次点"开始"后才会有声音。
